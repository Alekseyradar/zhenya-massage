# Женя массажист

Одностраничный сайт для массажиста Жени: услуги, описание специалиста, отзывы, полезные статьи, контакты и форма записи.

## Что есть на сайте

- Первый экран с главным предложением и кнопкой записи.
- Блок услуг с ценами.
- Блок "Обо мне" с фотографией Жени.
- Этапы работы.
- Отзывы клиентов.
- Блог с полезными статьями.
- Форма записи с выбором услуги, даты и желаемого времени.
- Быстрая кнопка WhatsApp.

## Структура проекта

```text
.
├── index.html
└── assets/
    ├── hero-spa-oils.jpg
    └── zhenya-about.jpg
```

`index.html` содержит всю разметку, стили и JavaScript.  
`assets/` хранит изображения, которые используются на сайте.

## Как посмотреть сайт локально

Откройте папку проекта и запустите локальный сервер:

```bash
python3 -m http.server 8000
```

После запуска сайт будет доступен по адресу:

```text
http://localhost:8000
```

## Как редактировать

- Тексты, цены, контакты и блоки страницы редактируются в `index.html`.
- Изображение первого экрана подключено в CSS-классе `.hero-bg`.
- Фото в блоке "Обо мне" находится в секции `id="about"`.
- Поля формы записи находятся в секции `id="booking"`.
