# Светоч

Предварительный одностраничный сайт для массажного проекта "Светоч" в Санкт-Петербурге, Пушкин.

## Что есть на сайте

- Первый экран с премиальным тёплым настроением и быстрыми CTA.
- Услуги и цены.
- Каталог форматов.
- Блок о подходе Евгения.
- Отзывы.
- Контакты, адресная зона и ссылка на карту.
- Способы оплаты для первой версии.
- Форма заявки с базовой валидацией и модальным подтверждением.
- Быстрые кнопки Telegram и WhatsApp.

## Структура

```text
.
├── index.html
└── assets/
    ├── hero-spa-oils.jpg
    └── zhenya-about.jpg
```

`index.html` содержит разметку, стили и JavaScript без внешнего фреймворка.

## Как посмотреть локально

```bash
python3 -m http.server 8000
```

После запуска сайт доступен по адресу:

```text
http://localhost:8000
```
